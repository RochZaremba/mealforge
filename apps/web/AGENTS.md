# Web/PWA-specific agent rules

- Follow root AGENTS.md, docs/UX_FLOWS.md, docs/PRD.md.
- Mobile-first Polish UX. Five slots, repeat controls, swipe/swap/undo with keyboard alternative, household shared state.
- Do not display fake nutrition precision or fictitious photos. Use clearly attributed licensed images only.
- Every user-visible success state must correspond to confirmed API acceptance or clearly marked pending offline state.
- Respect accessible focus, touch target sizes, contrast, loading/error/empty states, and offline modes.
- Add Playwright flows for all cross-module actions.
