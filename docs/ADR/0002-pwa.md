# ADR-0002 — PWA zamiast natywnych oddzielnych aplikacji

- **Status:** Accepted (baseline architecture)
- **Date:** 2026-10-10
- **Owner:** MealForge architecture

## Context

Wymagana praca na telefonie, desktopie i prywatnym serwerze bez dublowania zespołu.

## Decision

Next.js responsywne PWA, Service Worker offline READ dla ostatnich planów/zakupów + kolejka bezpiecznych mutacji. Notyfikacje tylko gdy platforma i zgoda pozwalają.

## Consequences

Jeden kod UI, mobilna instalacja i mniejsze koszty. Ograniczenia Safari/iOS/offline rozwiązywane degradacją z komunikatem zamiast fałszywej obietnicy.

## Alternatives

Flutter jako drugi klient i natywne aplikacje — odroczone.
